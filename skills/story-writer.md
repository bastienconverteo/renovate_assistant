# Skill: story-writer

Trigger: "write stories for <requirement or datapoint>".

1. Read the requirement, datapoint rows, related decisions, and country mappings.
2. If table facts matter, ask Genie and record the answer with date.
3. Draft stories with `templates/story.md`: Given/When/Then criteria, countries in or out, tests per country with expected results, dependencies, open questions.
4. Propose rows for `registers/stories.csv`; save after approval. Note the ServiceNow number when known.
